# Stellar injection fixture

The M5V broad-band stellar spectrum is the optical excerpt of the STScI Pickles UVK library `pickles_uk_44.fits`, downloaded from https://ssb.stsci.edu/cdbs/deliveries/etc/trds.24.3xxxx/grid/pickles/dat_uvk/pickles_uk_44.fits . The library index identifies spectral type M5V. Flux is normalized to its median over 5780–9810 Angstrom. Original-file SHA256: 19d828f087183db7c1b86bebe5e4c6a49fddfa492eb8e2cb4c14bf989a7ad610.

This low-resolution empirical spectrum tests molecular-band and continuum contamination. The separate synthetic narrow-absorption tests cover unresolved stellar structure; it is not a high-resolution M-star atlas.
