# Individual-fiber LSF coverage

## Empirical reference FITS products

`build_lsf_references.py` constructs per-physical-fiber, per-channel convex LSF averages using the verified current Gaia flux ratio <0.1, preserving the separate <0.01 flag. Products cover the analyzed survey sample, individual actual camera epochs, and epoch–lunation groups. The portable `lsf_calibration/` directory contains compact FITS, a loader, 2D figures, the named HTML report with local MathJax, and methodological README files. Full weight records and calculation archives are in the separate sibling `lsf_reference_audit/`. Survey pooling is descriptive; the other scopes preserve calibration epochs.

The averaging uses one dispersion-dependent scalar weight for the whole surface and equal observing-night mass before robust downweighting. Full methods and the common FITS schema are documented in `LSF_REFERENCES_METHODS.md`; the published README includes actual numerical coverage. `skysub.sky_decomp.lsf_reference.load_reference_lsf` loads a single FITS or a B/R/Z mapping of independently selected files into the existing `LSFSurfaceState`, for direct `fixed_lsf_state` use with SolarBlue and no LSF optimization. `load_lsf_from_sframe` checks the target physical fiber and native grid; its default `scope="lunation"` chooses the nearest sampled lunation within each camera epoch, while explicit `scope="survey"` loads the pooled survey mean without requiring epoch or time provenance. `reference_covariance` reads the separate technical archive when requested. Conditional mean errors and empirical scatter have distinct interpretations; predictive transfer accuracy requires separate validation.
